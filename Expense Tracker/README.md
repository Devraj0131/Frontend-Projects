# Expense Tracker

A simple expense tracker for recording spending and seeing totals by category.

## Features

- Add, edit, and delete expenses
- Organize expenses by category
- View the total spent and totals for each category
- Save expenses in the browser using local storage

## Built with

- HTML
- CSS
- JavaScript

## Live demo

[Open the Expense Tracker](https://devraj0131.github.io/Frontend-Projects/Expense%20Tracker/)

## Run locally

1. Download or clone this repository.
2. Open the `Expense Tracker` folder.
3. Open `index.html` in a browser.
