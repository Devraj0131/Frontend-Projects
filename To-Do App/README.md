# To-Do App

A simple task manager for keeping track of everyday tasks. Add tasks, mark them complete, and remove them when they’re no longer needed.

## Features

- Add new tasks
- Mark tasks as complete or active
- View all, active, and completed tasks
- Delete tasks
- See total, completed, and remaining task counts
- Tasks stay saved in this browser using local storage

## Built with

- HTML
- CSS
- JavaScript

## Live demo

[Open the To-Do App](https://devraj0131.github.io/Frontend-Projects/To-Do%20App/)

## Run locally

1. Download or clone this repository.
2. Open the `To-Do App` folder.
3. Open `index.html` in a browser.
